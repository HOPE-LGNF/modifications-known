# 新手引导（交互漫游导览）分析

> 状态：仅分析，本轮不实现。  
> 目标：首次启动时用 5–8 步交互导览，让用户在两分钟内理解“版本实例 → 启动 → 装模组 → 启用/分组 → 存档隔离”。

## 1. 导览范围

| 步骤 | 页面 | 锚点 | 文案重点 | 动作 |
|---|---|---|---|---|
| 1 | 概览 | 顶部版本下拉栏 | 版本 = 独立实例；下拉切换当前版本 | 打开下拉或仅高亮 |
| 2 | 概览 | hero 启动按钮 | 启动前会准备该版本的 BepInEx 与存档 | 无 |
| 3 | 设置 | “添加实例” | 一次选择 exe/目录；Steam 库可重新探测 | 需要时跳转设置 |
| 4 | 模组发现 | 搜索框 + 详情“下载并安装” | NXM 与免费账号限制 | 无 |
| 5 | 已安装 | Mod 组工具栏 | 保存快照、切换组拦截、应用组 | 无 |
| 6 | 设置 | 存档隔离说明 | 正式版/试玩版不串档；首次迁移先备份 | 无 |

## 2. 交互与状态

- 首次启动（`OnboardingCompleted == false`）自动播放；右下角“跳过”立即标记完成。
- 每步“上一步 / 下一步 / 完成”；Esc 退出；播放中禁用底层点击（或只高亮锚点区域）。
- 设置页增加“重新播放新手引导”。
- 完成状态写入 `settings.json`（新增 key `OnboardingCompleted`，默认 false），不写入日志。
- 窗口尺寸变化时重新计算锚点；锚点所在页未激活时先导航，再等布局完成（`LayoutUpdated` 或延迟一帧）。

## 3. 技术方案（Avalonia）

- **覆盖层**：MainWindow 最上层放一个 `Canvas`，铺半透明遮罩，用 4 块矩形围出“聚光灯”空洞，避免依赖裁剪路径；空洞用 `RenderTransform` 跟随锚点。
- **锚点**：给目标控件加 `x:Name`，通过 `TransformToVisual(overlay)` 取矩形；不要用硬编码像素。
- **气泡卡**：圆角 Border + 阴影，放在空洞上方/下方，按剩余空间自动翻转；箭头用 Path 绘制。
- **不新建 Window**：避免焦点与 DPI 切换问题；遮罩层只拦截指针，不改变原页面布局。
- **可测试性**：把步骤表抽成 `OnboardingStep` 列表（Key、AnchorName、Title、Body、PageKey），后续可单测顺序与持久化。
- **无障碍**：焦点限制在气泡卡内，提供键盘操作；文案走资源，便于以后本地化。

## 4. 风险与暂缓原因

1. 当前页面大量使用 `ItemsControl`/`ScrollViewer`，部分锚点（模组卡、详情按钮）在滚动后才存在，需要“先滚动到可见”逻辑。
2. 版本下拉栏与设置页共用实例状态，导览中切换实例会影响后续步骤的数据，需要只读演示或固定数据。
3. 遮罩空洞在 Windows 高 DPI + 多屏下的坐标换算需要真机验证。
4. 本轮优先修实例探测/删除、BepInEx 与设置页，导览留到这些交互稳定后再做，避免导览文案随 UI 反复改。

## 5. 建议实施顺序

1. 抽出步骤模型与持久化 key；
2. 实现遮罩 + 锚点定位（先只支持概览/设置两页）；
3. 接入 5 步主流程，补“跳过/重播”；
4. 真机验证 DPI、窗口缩放、键盘；
5. 最后补模组发现/已安装页的滚动锚点。
